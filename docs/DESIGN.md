# บันทึกงานออกแบบ (UX/UI)

## หลักการ

1. **เข้าเล่นได้ใน 30 วินาที** — สแกน → ชื่อ → ทีม → เล่น ไม่มีสมัครสมาชิก ไม่มีติดตั้ง
2. **นิ้วโป้งมือเดียว** — ปุ่มทุกปุ่มสูงอย่างน้อย 44–48px เมนูหลักอยู่ล่างจอ เผื่อ safe-area ของเครื่องมีรอยบาก
3. **รู้ผลทันที** — ทุกการแตะมีเสียง ตัวเลขลอย การสั่น; จบเกมมีดาว 3 ระดับ + confetti
4. **รอบสั้น เล่นซ้ำง่าย** — 20–120 วินาทีต่อเกม ปุ่ม "เล่นอีกครั้ง" และ "เกมถัดไป" อยู่บนหน้าสรุปผล
5. **ยุติธรรม** — ทุกเกมเต็มราว 1,000 แต้ม กดมั่วไม่ได้คะแนน (มีบทลงโทษเมื่อตอบผิด) ทีมไม่เท่ากันใช้ค่าเฉลี่ยได้

## ภาพลักษณ์

แนว "เกมโชว์": สีแบนสด ชิ้นส่วนหนาเหมือนของเล่นที่กดได้

- **ไม่ใช้** gradient, เงาฟุ้ง, กระจกฝ้า — ทุกอย่างเป็นสีพื้นทึบ
- พื้นหลังคราม `#2d1e9e` มีลายเรขาคณิตจาง ๆ; ตอนเล่นเกม ทั้งจอเปลี่ยนเป็นสีประจำเกมนั้น
- การ์ดขาว ตัวอักษรกรมท่า `#17124a`; ทุกชิ้นที่กดได้มี "ขอบล่างหนา" (`--edge`) และยุบลง 4px เมื่อกด
- สีหลัก: แดง `#e03131` · ฟ้า `#1c8ef0` · เหลือง `#ffc93c` · เขียว `#12a65c` · ชมพู `#e6399b` · ส้ม `#ff5a1f`
- ปุ่มหลักและคะแนนใช้สีเหลืองเสมอ
- ของตกแต่งเอียงเล็กน้อย (ไอคอนเกม, ป้ายรหัสห้อง, ป้าย "สถิติใหม่") ให้ดูเหมือนสติกเกอร์ ไม่เป็นตารางเป๊ะ
- ไอคอนเกมและเมนูวาดเองเป็น SVG ใน `js/icons.js` (อีโมจิเหลือเฉพาะตัวละคร มาสคอตทีม และของในเกม)
- การเคลื่อนไหว: เปลี่ยนหน้าแบบ cross-fade (View Transitions), ใช้จังหวะเด้ง `--spring` กับสิ่งที่ผู้เล่นแตะ
- ฟอนต์ Kanit (น้ำหนัก 400/500/600/800) มีฟอนต์ระบบเป็นตัวสำรองเมื่อออฟไลน์
- เคารพการตั้งค่า "ลดการเคลื่อนไหว" ของเครื่อง: ปิดแอนิเมชันตกแต่งและ confetti

## เพิ่มเกมใหม่

เพิ่ม object ใน `js/games.js` แล้วใส่ในอาร์เรย์ `GAMES`:

```js
const mygame = {
  id: 'mygame', name: 'ชื่อเกม', icon: I.targets, grad: ['#ff5a1f'], skill: 'ทักษะ',  // grad[0] = สีประจำเกม
  desc: 'คำโปรยสั้น ๆ', how: 'กติกา', stars: [300, 600, 900],
  start(api) {
    api.stage.innerHTML = `...`;       // วาด UI
    api.timer(30, api.end);            // จับเวลา 30 วิ แล้วจบเกม
    // api.add(50, event)  ให้คะแนน      api.miss()  เอฟเฟกต์ผิด
    // api.after(ms, fn)   ตั้งเวลา (ล้างให้อัตโนมัติเมื่อออกจากเกม)
  }
};
```
