# เปิดกระดานคะแนนสด (ไม่บังคับ)

ถ้าไม่ทำขั้นตอนนี้ เกมยังเล่นได้ครบ เพียงแต่คะแนนของแต่ละคนจะอยู่ในเครื่องตัวเอง

1. สร้างโปรเจกต์ที่ [supabase.com](https://supabase.com) (แพ็กเกจฟรีเพียงพอสำหรับงานอบรมทั่วไป)
2. เปิด **SQL Editor** → วางเนื้อหาไฟล์ `supabase/schema.sql` → Run
3. ไปที่ **Project Settings → API** คัดลอก *Project URL* และ *publishable (anon) key*
4. ใส่ใน `config.js`:
   ```js
   window.GS_CONFIG = { supabaseUrl: 'https://xxxx.supabase.co', supabaseKey: 'ey...' };
   ```
5. นำขึ้นโฮสต์ใหม่ หน้าผู้จัดจะมีป้าย **● LIVE**

## ข้อควรรู้

- ระบบไม่มีการล็อกอิน ผู้ที่มี key สามารถส่งคะแนนเองได้ เหมาะกับกิจกรรมสนุก ๆ ไม่เหมาะกับการแข่งชิงรางวัลมูลค่าสูง
- ทดสอบกับจำนวนเครื่องจริงก่อนวันงานเสมอ (ดู `EVENT_RUNBOOK.md`)
- จบงานแล้วล้างข้อมูล: `delete from gs_scores where room = 'รหัสห้อง';`

## แก้เนื้อหาเกม

เปิด `js/data.js`
- `QUIZ` — คำถาม 4 ตัวเลือก **ตัวเลือกแรกคือคำตอบที่ถูก** (เกมสลับตำแหน่งให้เอง) ควรมีอย่างน้อย 10 ข้อ
- `WORDS` — คำศัพท์ + คำใบ้ สำหรับเกมสลับอักษร (แนะนำ 3–8 ตัวอักษร)
