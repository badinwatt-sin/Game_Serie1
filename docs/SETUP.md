# เปิดกระดานคะแนนสดและโพล

ถ้าไม่ทำขั้นตอนนี้ เกมทั้ง 10 ยังเล่นได้ครบ แต่คะแนนของแต่ละคนจะอยู่ในเครื่องตัวเอง และ **ใช้โพล/แบบสำรวจไม่ได้**

> เคยรัน `schema.sql` เวอร์ชันก่อนมีโพลแล้ว? รันไฟล์ซ้ำได้เฉพาะส่วนใต้หัวข้อ "โพล / แบบสำรวจ"

1. สร้างโปรเจกต์ที่ [supabase.com](https://supabase.com) (แพ็กเกจฟรีเพียงพอสำหรับงานอบรมทั่วไป)
2. เปิด **SQL Editor** → วางเนื้อหาไฟล์ `supabase/schema.sql` → Run
3. รัน `supabase/admin.sql` ต่อ แล้วตั้งรหัสผ่านผู้จัดด้วยคำสั่งท้ายไฟล์นั้น (ถ้าข้ามขั้นนี้ แท็บ "ผู้จัด" จะเข้าได้โดยไม่ต้องใช้รหัส)
4. ไปที่ **Project Settings → API** คัดลอก *Project URL* และ *publishable (anon) key*
5. ใส่ใน `config.js`:
   ```js
   window.GS_CONFIG = { supabaseUrl: 'https://xxxx.supabase.co', supabaseKey: 'ey...' };
   ```
6. นำขึ้นโฮสต์ใหม่ หน้าผู้จัดจะมีป้าย **● LIVE**

## รหัสผ่านผู้จัด

- แท็บ "ผู้จัด" ต้องใส่รหัสผ่านก่อนเข้า ฐานข้อมูลเป็นผู้ตรวจ และการสร้าง/ปิด/ลบโพลทำได้เฉพาะผู้ที่มีรหัส
- รหัสผ่านเก็บแบบเข้ารหัส (bcrypt) ในตาราง `gs_admin` ไม่อยู่ในโค้ดหน้าเว็บ
- เปลี่ยนรหัสผ่าน: รันคำสั่งท้ายไฟล์ `supabase/admin.sql` ใน SQL Editor โดยใส่รหัสใหม่
- เครื่องที่ล็อกอินแล้วจะจำรหัสไว้จนกว่าจะกด "ออกจากระบบผู้จัด"

## ข้อควรรู้

- ผู้เล่นไม่ต้องล็อกอิน ผู้ที่มี key จึงยังส่งคะแนนของตัวเองได้เอง (รหัสผ่านผู้จัดคุ้มครองเฉพาะงานของผู้จัด) เหมาะกับกิจกรรมสนุก ๆ ไม่เหมาะกับการแข่งชิงรางวัลมูลค่าสูง
- ทดสอบกับจำนวนเครื่องจริงก่อนวันงานเสมอ (ดู `EVENT_RUNBOOK.md`)
- จบงานแล้วล้างข้อมูล: `delete from gs_scores where room = 'รหัสห้อง'; delete from gs_polls where room = 'รหัสห้อง';`
- ต้องการเก็บผลแบบสำรวจ: ส่งออกตาราง `gs_votes` เป็น CSV จาก Supabase Table Editor ก่อนลบ

## แก้เนื้อหาเกม

เปิด `js/data.js`
- `QUIZ` — คำถาม 4 ตัวเลือก **ตัวเลือกแรกคือคำตอบที่ถูก** (เกมสลับตำแหน่งให้เอง) ควรมีอย่างน้อย 10 ข้อ
- `WORDS` — คำศัพท์ + คำใบ้ สำหรับเกมสลับอักษร (แนะนำ 3–8 ตัวอักษร)
