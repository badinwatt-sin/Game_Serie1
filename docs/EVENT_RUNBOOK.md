# Runbook สำหรับทีมอีเวนต์

## ก่อนวันงาน (T-7 ถึง T-1)

- [ ] นำเว็บขึ้นโฮสต์ https และทดลองเปิดจากมือถือ iOS + Android
- [ ] แก้คำถาม/คำศัพท์ใน `js/data.js` ให้ตรงกับหลักสูตร (ถ้าต้องการ)
- [ ] ซ้อมทั้ง flow กับอย่างน้อย 5 เครื่อง: เข้าห้อง เตรียมเกม ปล่อย จบรอบ ข้อความ อันดับ โพล
- [ ] เตรียมลำดับเกมและคำถามโพลไว้ล่วงหน้า
- [ ] เช็ก Wi-Fi / สัญญาณมือถือในห้อง (ตัวเกมโหลดครั้งเดียวราว 150 KB แล้วเล่นต่อได้แม้เน็ตหลุด)
- [ ] เตรียมของรางวัล: ทีมชนะ, MVP รายบุคคล, รางวัลพัฒนาการ

## อุปกรณ์

- โน้ตบุ๊ก/แท็บเล็ตต่อโปรเจกเตอร์ เปิดหน้า **สำหรับผู้สอน** (จอกว้างจะแสดง QR ซ้าย แผงควบคุมขวา)
- ผู้สอนคุมจากมือถืออีกเครื่องได้ โดยล็อกอินแล้วเปิดห้องเดียวกัน
- ลำโพง (ไม่บังคับ) · ป้าย QR พิมพ์สำรองวางบนโต๊ะ สำหรับงาน 50 คนขึ้นไป
- ที่ชาร์จ / power bank สำรอง

## คิวงาน (ตัวอย่าง 20 นาที)

จอโปรเจกเตอร์เปิด **หน้า Live** ตลอด ผู้สอนสั่งงานจากแถบล่างของหน้า Live หรือจากห้องควบคุมบนมือถืออีกเครื่อง

| เวลา | ผู้สอน / ทีมเทคนิคกด | จอผู้เล่น | หน้า Live |
|------|----------------------|-----------|-----------|
| 0:00 | ล็อกอิน เปิดห้อง เปิดหน้า Live กด "เต็มจอ" | — | QR ใหญ่ |
| 0:01 | พิธีกรอธิบาย: สแกน → สร้างตัวตน → รอ | สร้างตัวตน แล้วหน้ารอ | ตัวละครเด้งเข้าผนัง |
| 0:04 | เช็กจำนวนคนมุมขวาบนให้ครบ | | |
| 0:05 | เตรียมเกมอุ่นเครื่อง → ปล่อยเกม | นับถอยหลัง แล้วเล่น | นับถอยหลัง → เลนแข่ง |
| 0:07 | จบรอบและประกาศผล | ผลของตัวเอง | โพเดียม |
| 0:08 | รอบที่ 2–4: เตรียม → ปล่อย → จบ (รอบละราว 3 นาที) | | |
| 0:17 | กลับหน้ารอ แล้วเปิด "แสดงอันดับรวม" | อันดับทีมและบุคคล | อันดับรวม |
| 0:19 | เปิดโพลสะท้อนคิด ส่งต่อผู้สอน | คำถามจากผู้สอน | ผลโหวตสด |

## ปรับตามขนาดกลุ่ม

| ขนาด | รูปแบบ | หมายเหตุ |
|------|--------|----------|
| 2–10 คน | เดี่ยว หรือ 2 ทีม | |
| 10–40 คน | 3–6 ทีม | ผู้สอนคุมเองได้คนเดียว |
| 40–100 คน | 6–12 ทีม | มี staff ช่วย 1 คนต่อ 30 คน · พิมพ์ QR วางทุกโต๊ะ |
| 100+ คน | 12 ทีม หรือแบ่งหลายห้อง | ยังไม่เคยทดสอบที่ขนาดนี้ ต้องซ้อมกับเครื่องจริงและเช็กเน็ตก่อน |

## แผนสำรอง

| ปัญหา | ทางแก้ |
|-------|--------|
| สแกน QR ไม่ได้ | เปิดเว็บแล้วพิมพ์รหัสห้อง 5 ตัว |
| เน็ตช้า/หลุด | เกมที่โหลดแล้วเล่นต่อได้ คะแนนเก็บในเครื่อง และส่งขึ้นกระดานใหม่เมื่อจบเกมถัดไป |
| จอผู้เล่นไม่เปลี่ยนตาม | รอ 4–5 วินาที ถ้ายังไม่เปลี่ยนให้ผู้เล่นรีเฟรชหน้า |
| มีคนยังไม่เข้าเกมตอนปล่อย | รอได้ คนที่เข้าช้ายังเล่นรอบนั้นได้จนกว่าจะกดจบรอบ |
| ปล่อยเกมผิด | กด "จบรอบ" แล้ว "กลับหน้ารอ" คะแนนรอบนั้นยังถูกนับ ถ้าไม่ต้องการให้นับ แจ้งผู้ดูแลระบบลบคะแนนรอบนั้น |
| หน้า Live ไม่มีเสียง | คลิกที่หน้าจอหนึ่งครั้ง (เบราว์เซอร์ต้องมีการคลิกก่อนจึงเล่นเสียงได้) |
| ตัวละครที่อยากได้ถูกเลือกไปแล้ว | เลือกตัวอื่น มี 153 ตัว หรือขอให้ผู้สอนนำคนที่เข้าผิดออกจากห้อง |
| ชื่อไม่เหมาะสม / เข้าซ้ำ | แท็บ "ผู้เล่น" กดกากบาทท้ายชื่อเพื่อนำออก |
| มือถือไม่มี/แบตหมด | จับคู่เล่นเครื่องเดียวกัน (โหมดคู่หู) |
| เลือกทีมผิด | แตะการ์ดชื่อตัวเองมุมซ้ายบน → แก้ไขตัวตน |
| ปิดเสียง | แตะการ์ดชื่อตัวเอง → เสียง: ปิด |
