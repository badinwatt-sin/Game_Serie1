# Game Serie 1

เว็บแอปมือถือสำหรับกิจกรรมฝึกอบรม / Team Building: **10 มินิเกมสะสมคะแนน + โพลสด** โดย **ผู้สอนเป็นผู้ควบคุมกิจกรรม** และผู้เข้าร่วมมีหน้าที่อย่างเดียวคือเข้ามาเล่น ไม่ต้องติดตั้งแอป ไม่ต้องสมัครสมาชิก

## บทบาท

| | ผู้เล่น | ผู้สอน |
|---|---|---|
| เข้าใช้งาน | สแกน QR หรือกรอกรหัสห้อง 5 ตัว | แตะ "สำหรับผู้สอน" แล้วใส่รหัสผ่าน |
| ทำอะไรได้ | สร้างตัวตน → เล่นเกมที่ผู้สอนเปิด → ตอบคำถาม → ดูอันดับเมื่อผู้สอนสั่งโชว์ | สร้างห้อง · เปิด/ปิดเกม · ส่งข้อความขึ้นทุกจอ · โชว์/ซ่อนอันดับ · ตั้งโพล · ให้โบนัสทีม · นำผู้เล่นออก |
| หน้าจอ | หน้าเดียว เปลี่ยนเองตามคำสั่งผู้สอน | ห้องควบคุม (จอกว้าง: QR ซ้าย แผงควบคุมขวา) |

## ตัวตนของผู้เล่น

- ชื่อเล่น
- ตัวละครอีโมจิ 153 ตัว 4 หมวด — **ห้ามซ้ำกันในห้อง** (ฐานข้อมูลเป็นผู้กัน ตัวที่มีคนเลือกแล้วจะกดไม่ได้)
- สีประจำตัว 8 สี
- สไตล์ของฉัน (นักคิด, นักลุย, นักประสาน ฯลฯ) — ผู้สอนเห็นสัดส่วนสไตล์ของทั้งห้อง
- ทีม (ถ้าห้องเป็นแบบทีม) พร้อมจำนวนคนในแต่ละทีมเพื่อช่วยกระจายให้สมดุล

## เกม

⚡ ควิซสายฟ้า · จับคู่ความจำ · ไวกว่าแสง · สลับอักษร · คิดเลขเร็ว · สีหลอกตา · จำลำดับแสง · ตาไวจับผิด · ล่าดาว · เรียงเลขสายตาไว
ทุกเกมเต็มราว 1,000 แต้ม มีดาว 3 ระดับ เล่นซ้ำได้ระหว่างที่ผู้สอนเปิดอยู่ ระบบนับ **คะแนนที่ดีที่สุด** ของแต่ละเกม ตอบโพลได้ข้อละ 50 แต้ม

## ติดตั้ง

ไฟล์ static ล้วน ไม่มีขั้นตอน build นำขึ้นโฮสต์ https ใดก็ได้ ต้องมีฐานข้อมูล Supabase สำหรับห้อง ผู้เล่น คะแนน และโพล — ขั้นตอนอยู่ใน [docs/SETUP.md](docs/SETUP.md)

ถ้า `config.js` ว่าง แอปจะทำงานเป็น **โหมดสาธิต**: เล่นเกมได้ทุกเกมบนเครื่องเดียว ไม่มีห้องและไม่มีผู้สอน

```bash
python3 -m http.server 8000   # ทดลองในเครื่อง
```
