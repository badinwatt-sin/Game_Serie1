เล่นได้ทั้ง **เดี่ยว** และ **ทีม** พร้อม **โพล/แบบสำรวจสด** รองรับตั้งแต่ 2 คนถึงหลายร้อยคน ผู้เล่นแค่สแกน QR — ไม่ต้องติดตั้งแอป ไม่ต้องสมัครสมาชิก

ทุกเกมมีคะแนนเต็มราว 1,000 แต้ม มีดาว 3 ระดับ และนับ **คะแนนที่ดีที่สุดของแต่ละเกม** รวมเป็นคะแนนสะสม

## เริ่มใช้งาน

ไม่มีขั้นตอน build — เป็นไฟล์ static ล้วน

```bash
python3 -m http.server 8000   # แล้วเปิด http://localhost:8000
```

นำขึ้นใช้งานจริงได้กับโฮสต์ static ใดก็ได้ (GitHub Pages, Netlify, Vercel ฯลฯ) ต้องเป็น **https** เพื่อให้ติดตั้งลงหน้าจอและเล่นออฟไลน์ได้

## วิธีเล่นในงาน

1. ผู้จัดเปิดแท็บ **ผู้จัด** → ใส่ชื่องาน จำนวนคน เลือกเดี่ยว/ทีม → ได้ **รหัสห้อง + QR** (ฉายขึ้นจอได้)
2. ผู้เล่นสแกน QR → ใส่ชื่อ เลือกตัวละคร เลือกทีม → เล่นได้ทันที
3. ดูผลที่แท็บ **คะแนน**
4. ผู้จัดตั้งคำถามที่ **ผู้จัด → โพล / แบบสำรวจ** ผู้เล่นตอบที่แท็บ **โพล** (ต้องเปิดกระดานสด)

### กระดานคะแนน 2 แบบ

| | ไม่ต้องตั้งค่า (ค่าเริ่มต้น) | กระดานสด (ตั้งค่า Supabase) |
|---|---|---|
| คะแนนผู้เล่น | เก็บในเครื่องของแต่ละคน | ส่งขึ้นจอกลางอัตโนมัติ |
| จอผู้จัด | จดคะแนนทีม / โบนัสด้วยมือ | อันดับทีม · เฉลี่ยต่อคน · บุคคล อัปเดตทุก 4 วิ |
| โพล / แบบสำรวจ | ใช้ไม่ได้ (คำตอบต้องรวมที่เซิร์ฟเวอร์กลาง) | ตัวเลือก · ให้ดาว 1–5 · คำตอบสั้น ผลขึ้นสด ตอบแล้วได้ 50 แต้ม |

## โครงสร้าง

```
index.html  config.js  sw.js  manifest.webmanifest
css/style.css      design system ทั้งหมด
js/app.js          หน้าจอ, router, ตัวครอบเกม (HUD/นับถอยหลัง/สรุปผล)
js/games.js        มินิเกม 10 เกม
js/polls.js        โพล/แบบสำรวจ (ฝั่งผู้เล่นและผู้จัด)
js/icons.js        ชุดไอคอน SVG ที่วาดเอง
js/data.js         คำถามควิซ + คำศัพท์  ← แก้ไฟล์นี้เพื่อใส่เนื้อหาของคุณ
js/core.js         state, เสียง, เอฟเฟกต์, รหัสห้อง
js/sync.js         ส่ง/ดึงคะแนนกระดานสด
supabase/schema.sql
```
