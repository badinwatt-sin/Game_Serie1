# Game Serie 1

เว็บแอปมือถือสำหรับกิจกรรมฝึกอบรม / Team Building: **10 มินิเกมสะสมคะแนน + โพลสด** โดย **ผู้สอนเป็นผู้ควบคุมกิจกรรม** และผู้เข้าร่วมมีหน้าที่อย่างเดียวคือเข้ามาเล่น ไม่ต้องติดตั้งแอป ไม่ต้องสมัครสมาชิก

## บทบาท

| | ผู้เล่น | ผู้สอน (Admin) |
|---|---|---|
| เข้าใช้งาน | สแกน QR หรือกรอกรหัสห้อง 5 ตัว | แตะ "สำหรับผู้สอน" แล้วใส่รหัสผ่าน |
| ทำอะไรได้ | สร้างตัวตน → เล่นรอบที่ผู้สอนปล่อย → ตอบคำถาม → ดูผล | สร้างห้อง · ปล่อยเกมทีละรอบ · จบรอบ · ส่งข้อความ · โชว์อันดับ · ตั้งโพล · โบนัสทีม · นำผู้เล่นออก |
| หน้าจอ | หน้าเดียว เปลี่ยนเองตามคำสั่งผู้สอน | ห้องควบคุม + หน้า Live สำหรับฉายขึ้นจอ |

## รอบการแข่ง: ปล่อยพร้อมกัน เล่นเท่าเทียม

1. **เตรียม** — ผู้สอนเลือกเกม ทุกจอแสดงคำอธิบายเกมและรอสัญญาณ
2. **ปล่อย** — ทุกเครื่องนับถอยหลังพร้อมกันตามเวลาเซิร์ฟเวอร์ (ไม่ขึ้นกับนาฬิกาของเครื่อง) แล้วเริ่มเอง
3. **เล่น** — ทุกคนได้โจทย์ชุดเดียวกัน ลำดับเดียวกัน และเล่นได้คนละ 1 ครั้งต่อรอบ
4. **จบรอบ** — ผู้สอนกดจบ ทุกเครื่องที่ยังเล่นอยู่หยุดพร้อมกัน แล้วประกาศผล

คะแนนสะสม = ผลรวมคะแนนทุกรอบ + คะแนนตอบโพล (ข้อละ 50) + โบนัสทีมจากผู้สอน

## หน้า Live

เปิดจากห้องควบคุม แล้วฉายขึ้นจอ ฉากเปลี่ยนตามสถานะห้อง มีแถบสั่งงานด้านล่าง (กด Space = ปุ่มหลัก)

| สถานะ | บนจอ |
|-------|------|
| รอคนเข้าห้อง | QR ใหญ่ + ผนังตัวละคร คนใหม่เด้งเข้ามาพร้อมเสียง |
| เตรียมเกม | ชื่อเกมและวิธีเล่นตัวใหญ่ |
| ปล่อยเกม | นับถอยหลังเต็มจอ |
| กำลังเล่น | เลนแข่งสด 8 อันดับแรกสลับตำแหน่งตามคะแนน · จำนวนคนที่เล่นจบ · นาฬิกา · คะแนนทีมของรอบ |
| จบรอบ | โพเดียม 3 อันดับ เปิดทีละขั้น พร้อมพลุกระดาษ · อันดับทีมของรอบและอันดับรวม |
| มีโพลเปิดอยู่ | คำถามและผลโหวตสดตัวใหญ่ |
| ผู้สอนเปิด "แสดงอันดับ" | อันดับรวมทีมและบุคคล |

## ตัวตนของผู้เล่น

- ชื่อเล่น
- ตัวละครอีโมจิ 153 ตัว 4 หมวด — **ห้ามซ้ำกันในห้อง** (ฐานข้อมูลเป็นผู้กัน ตัวที่มีคนเลือกแล้วจะกดไม่ได้)
- สีประจำตัว 8 สี
- สไตล์ของฉัน (นักคิด, นักลุย, นักประสาน ฯลฯ) — ผู้สอนเห็นสัดส่วนสไตล์ของทั้งห้อง
- ทีม (ถ้าห้องเป็นแบบทีม) พร้อมจำนวนคนในแต่ละทีมเพื่อช่วยกระจายให้สมดุล

## เกม

⚡ ควิซสายฟ้า · จับคู่ความจำ · ไวกว่าแสง · สลับอักษร · คิดเลขเร็ว · สีหลอกตา · จำลำดับแสง · ตาไวจับผิด · ล่าดาว · เรียงเลขสายตาไว
ทุกเกมเต็มราว 1,000 แต้ม มีดาว 3 ระดับ

## ติดตั้ง

ไฟล์ static ล้วน ไม่มีขั้นตอน build นำขึ้นโฮสต์ https ใดก็ได้ ต้องมีฐานข้อมูล Supabase สำหรับห้อง ผู้เล่น คะแนน และโพล — ขั้นตอนอยู่ใน [docs/SETUP.md](docs/SETUP.md)

ถ้า `config.js` ว่าง แอปจะทำงานเป็น **โหมดสาธิต**: เล่นเกมได้ทุกเกมบนเครื่องเดียว ไม่มีห้องและไม่มีผู้สอน

```bash
python3 -m http.server 8000   # ทดลองในเครื่อง
```

```
index.html  config.js  sw.js  manifest.webmanifest
css/style.css      design system
js/app.js          หน้าจอผู้เล่น (เข้าห้อง, ตัวตน, เวที, เล่นเกม) และผู้สอน (ห้องควบคุม)
js/games.js        มินิเกม 10 เกม          js/data.js   คำถามควิซ + คำศัพท์
js/live.js         หน้า Live สำหรับฉายจอ    js/ui.js     ชิ้นส่วน UI ที่ใช้ร่วมกัน
js/polls.js        โพล                    js/sync.js   เชื่อมฐานข้อมูล, เวลาเซิร์ฟเวอร์, รอบการแข่ง
js/core.js         state, เสียง, เอฟเฟกต์, ชุดตัวตน    js/icons.js  ไอคอน SVG
supabase/          schema.sql → admin.sql → rooms.sql
```
